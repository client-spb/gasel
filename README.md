# Газель Серёги — дальнобой по-русски

Браузерная аркада про красную Газель с красной будкой и водителя Серёгу, который везёт грузы через всю Россию: из Москвы во Владивосток.

## Запуск

Откройте `index.html` в браузере. Сборка, сервер и фреймворки не нужны: обычные HTML, CSS и JavaScript.

## Что внутри

- **12 рейсов** через 7 зон: Подмосковье, Поволжье, Урал, степь, тайга, Байкал, Приморье. У каждой свой фон в три слоя параллакса, своя погода и покрытие дороги (асфальт, грунтовка, грязь, снег, лёд).
- **Физика Газели**: подвеска, проскальзывание колёс, задний привод (в гараже можно купить 4×4), управление в воздухе, сальто.
- **Груз в будке**: арбузы, яйца, холодильник «Бирюса», вещи тёщи с котом, гуси, баяны, самовары, телевизор для мамы. От жёстких ударов груз бьётся, а двери будки распахиваются, и груз вылетает на дорогу.
- **Жизнь на трассе**: коровы (прогоняются сигналом), посты ДПС со штрафами за превышение 60 км/ч, лось, медведь в ушанке, собака, бабушка на остановке, рекламные щиты с шутками.
- **Бонусы**: канистры с 92-м, гаечный ключ (чинит груз), чебурек (турбо), магнит для монет.
- **Гараж**: мотор, подвеска, шины, бак, крепёж груза (по 5 ступеней), полный привод, сигналы («Кукарача», «Паровоз», «Корова») и тюнинг: люстра, кенгурятник, хромовые колпаки, флажок, ёлочка-вонючка, спойлер.
- **Радио в кабине**: 5 станций со своей музыкой и ведущими.
- **Прочее**: бесконечный режим, 18 достижений, ежедневная премия, рейтинг, «Поделиться», «кум Валера» для эвакуации, если Газель застряла или легла на бок.

Управление: педали на экране, тап по правой и левой половине экрана, на ПК клавиши ← → (или A/D), пробел для сигнала, R для радио, Esc для паузы.

## Структура

- `index.html` — разметка и SVG-иконки.
- `css/` — стили и локальные шрифты.
- `js/` — код игры: `physics.js`, `terrain.js`, `world.js`, `render.js`, `ui.js` и другие.
- `img/` — PNG и JPG: спрайты, фоны, текстуры.
- `audio/` — музыка (MP3).
- `fonts/` — шрифты с кириллицей.
- `tools/` — генераторы графики (`node tools/build-art.js`, нужен Playwright) и музыки (`python3 tools/music.py`, нужны numpy, scipy и ffmpeg). Для запуска игры они не нужны.
